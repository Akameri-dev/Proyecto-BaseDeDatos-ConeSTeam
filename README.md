# Proyecto Fase II - Sistema de Base de Datos CONESTEAM

## 📌 Descripción del Proyecto
Este proyecto consiste en el diseño, implementación y optimización de una Base de Datos Relacional desarrollada para la asignatura de **Bases de Datos (BD-UCV)**. El sistema abarca desde la definición de modelos conceptuales y esquemas (DDL) hasta la carga de datos (Inserts), lógica del negocio (Stored Procedures, Triggers, Funciones) y consultas de analítica/reportes (Queries).
